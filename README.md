# Expense-Dashboard-Next.js

![Next.js](https://img.shields.io/badge/Next.js-000000?style=for-the-badge\&logo=next.js\&logoColor=white)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge\&logo=tailwind-css\&logoColor=white)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=for-the-badge\&logo=typescript\&logoColor=white)

A modern, fully-responsive expense dashboard built with **Next.js**, **Tailwind CSS**, **shadcn/ui**, and **TypeScript**. Track and visualize your personal expenses effortlessly.

---

## 🌐 Live Demo

Check the live demo here:
[Expense Dashboard Demo](https://expense-dashboard-next-js.vercel.app/)

## 🚀 Features

* **Next.js + TypeScript**: High-performance, scalable, SEO-friendly
* **Tailwind CSS**: Clean, modern, and responsive design
* **shadcn/ui components**: Buttons, Cards, Forms, etc.
* Fully responsive: optimized for mobile, tablet, and desktop
* Modular sections included:

  * Dashboard overview
  * Add / Manage Expenses
  * Categories & Filters
  * Charts & Analytics
* Easy customization: colors, text, icons, images
* SEO-friendly: add metadata and Open Graph tags
* Clean & modular code structure

## 🛠 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Ak-AhmedFathi/Expense-Dashboard-Next.js.git
cd Expense-Dashboard-Next.js
```

### 2. Install dependencies

```bash
npm install
# or
pnpm install
# or
yarn install
```

### 3. Run the development server

```bash
npm run dev
# or
pnpm dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) to view the dashboard.

### 4. Build for production

```bash
npm run build
npm run start
# or
pnpm build && pnpm start
# or
yarn build && yarn start
```

## 📦 Deployment

Easily deploy on **Vercel** or **Netlify**:

1. Push the repo to GitHub
2. Connect your GitHub account to Vercel/Netlify
3. Select the branch (e.g., `main`)
4. Click "Deploy"
5. Add environment variables if needed (`.env`)
